# ASGate CRM - نظام إدارة علاقات العملاء والمبيعات

هذا المستودع يحتوي على كافة الملفات اللازمة لتشغيل نظام **ASGate CRM** محلياً أو رفعه ونشره عبر GitHub.

## التشغيل محلياً (Run Locally)

**المتطلبات الأساسية:** Node.js

1. تثبيت الحزم البرمجية:
   `npm install`
2. تشغيل النظام في بيئة التطوير:
   `npm run dev`
3. بناء النسخة النهائية للإنتاج:
   `npm run build`
